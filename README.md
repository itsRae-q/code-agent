# 国证自由现金流指数股票筛选系统

## 项目概述

本项目基于《国证自由现金流指数编制方案》技术规格文档，开发了一套完整的股票筛选和权重计算系统。该系统严格按照文档中规定的筛选规则，从A股市场中筛选出自由现金流水平较高且稳定性较好的股票，并计算相应的投资权重。

## 核心功能

### 1. 多层次筛选体系
- **基础条件筛选**：剔除ST、*ST等风险警示股票
- **流动性筛选**：剔除成交金额排名后20%的股票
- **行业筛选**：剔除金融和房地产行业股票
- **ROE稳定性筛选**：剔除ROE稳定性排名后10%的股票
- **现金流质量筛选**：要求自由现金流、经营现金流均为正
- **经营质量筛选**：剔除经营现金流占营业利润比例排名后30%的股票

### 2. 科学的权重分配
- 按自由现金流率（FCF Yield）排序选取前100只股票
- 基于自由现金流大小计算初始权重
- 单只股票权重上限10%，确保分散投资
- 权重标准化处理，总和为100%

## 文件结构说明

### 核心代码文件

1. **`simple_screener.py`** - 主要筛选程序
   - 实现完整的股票筛选流程
   - 包含8个筛选步骤的详细实现
   - 提供详细的筛选过程输出和统计信息
   - 生成最终的股票权重分配结果

2. **`data_generator.py`** - 测试数据生成器
   - 生成符合真实市场特征的模拟股票数据
   - 包含200只测试股票的完整财务和交易数据
   - 支持各种筛选条件的测试验证

3. **`stock_screener.py`** - 完整版筛选器（支持真实数据）
   - 集成akshare等数据接口
   - 支持从真实市场获取股票数据
   - 包含完整的错误处理和数据验证机制

4. **`requirements.txt`** - 项目依赖
   - 列出所有必需的Python包及版本要求

### 数据文件

1. **`fcf_index_results.csv`** - 筛选结果文件
   - 包含48只入选股票的详细信息
   - 股票代码、名称、行业、权重等完整数据
   - 自由现金流率、现金流数据等关键指标
