# 国证自由现金流指数（CNIFCF）计算系统

基于《国证自由现金流指数编制方案》开发的完整指数计算系统。

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 运行演示版本
python3 cnifcf_index_demo.py
```

## 主要文件

- `cnifcf_index_demo.py` - 演示版本（推荐使用）
- `cnifcf_index_calculator.py` - 网络版本（需要网络连接）
- `项目说明文档.md` - 详细说明文档
- `output/` - 计算结果输出目录

## 指数信息

- **指数代码**: 980092
- **基日**: 2012-12-31，基点: 1000
- **样本数量**: 100只股票
- **选样方法**: 基于自由现金流率的三步筛选
- **权重方法**: 按自由现金流加权，单只股票上限10%

## 输出结果

运行后将在`output/`目录生成：
- 指数成分股列表（Excel/CSV）
- 指数基本信息（JSON）
- 详细财务数据（Excel）
- 权重分析报告（JSON）

详细说明请参考 `项目说明文档.md`
